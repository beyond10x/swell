## Context

Slice 8 of 19, `classes` (`epic:slice-08-classes`; `docs/design/engine.md`, section 12, item 8). This story runs a base class: ClassDefinitionEvaluation (`#sec-runtime-semantics-classdefinitionevaluation`) as compiled code (item 2 of "Classes") for a class without heritage, fields, private names or static blocks: the class scope with its own name (uninitialized and immutable while the computed keys are evaluated), the prototype, F made from the constructor's template (the written `constructor` or the default one the parser made), every method, getter, setter, generator, async and async generator method, static or not, with literal or computed keys (non-enumerable, with its [[HomeObject]]; a computed static key `prototype` throws a `TypeError`), `prototype` and `constructor` with their attributes, the name of an anonymous class; the class binding in a block, at the top of a script in the declarative record (GlobalDeclarationInstantiation) and in eval code; F's [[Call]] throws a `TypeError` of F's realm; F's [[Construct]] for a base class makes `this` from NewTarget and runs `This; InitInstance; Pop` before its parameters when the class has instance elements; `Function.prototype.toString` of a class and of its methods. `super.x` in its methods runs through the instructions of `story:super-property-and-super-syntax`. It lifts the hold `class` of `story:class-syntax-and-early-errors`.

Edges: `story:class-syntax-and-early-errors` (the tree and the hold), `story:new-target-meta-property` (the frame's NewTarget and `function`), `story:super-property-and-super-syntax` (its list holds the 9 cases of `super.x` in a base class, and both stories write `compiler/src/{bytecode,disasm,expression,resolve}.rs`, `interp/dispatch.rs` and `interp/mod.rs`). Order 2, built beside `story:class-element-syntax-and-early-errors`.

It makes whole, as decision 7 of slice 8 and item 3 of "Classes" state, the class constructor's box `ClassConstructor { kind, instance_elements }` in a new file `crates/swell/src/object/class_constructor.rs`, held in `EcmascriptFunction.class: Option<Box<ClassConstructor>>`, with both slots from the start (`kind`: base, or derived, set from the operand `derived` of `MakeClassConstructor`, which `story:derived-classes-and-super-call` emits as `true` and adds no instruction for; `instance_elements`: the initializer of item 4, `None` here). It makes the mechanisms of item 4 that later stories fill, so that no later story adds a field or a structure: the instruction `InitInstance` and the base template's prologue; the emitter of the instance initializer with its two passes (private method adds first, then fields), each pass a function of its own that answers nothing here; the emitted step-4 sequence of the static elements in source order, `static_calls`, with one named arm per kind of static element; and one `CompileError::Tree` arm per element kind it does not compile, each in a function of its own (`compile_field` and `static_field_run`, `compile_static_block`, `compile_private_method`), which `story:public-class-fields`, `story:class-static-blocks` and `story:private-names-and-private-methods` replace. ## What later stories reuse

The class's compiled form (`crates/compiler/src/class.rs`, new) with its functions per element kind; the box `ClassConstructor` and its two slots; `InitInstance` and the base prologue; the initializer emitter's two passes (`initializer_private_methods`, filled by `story:private-names-and-private-methods`; `initializer_fields`, filled by `story:public-class-fields`); the step-4 sequence `static_calls`, whose arms call `static_field_run` (a run of static fields, filled by `story:public-class-fields`) and `compile_static_block` (a static block, filled by `story:class-static-blocks`), and `static_private_adds` before it (the static private methods added to F, `story:private-names-and-private-methods`); the base [[Construct]] of a class constructor and `push_construct_frame` with its NewTarget; the class binding at the top of a script and in eval code; `toString` of a class.

## Domain relations

- A class constructor → its prototype (one, by `prototype`, and back by `constructor`); a method → its [[HomeObject]] (the prototype, or F for a static method); a class constructor → its box (one, owned) and the box → at most one instance initializer — inferable (inferred from ECMA-262 `#sec-runtime-semantics-classdefinitionevaluation` and `#sec-ecmascript-function-objects`; no ess/1 document declares it: `spec/domains/host.yaml` holds no engine value, and ESS does not restate ECMA-262, `AGENTS.md`, "Rules").
