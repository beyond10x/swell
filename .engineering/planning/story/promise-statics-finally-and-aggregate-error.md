## What later stories reuse

The element functions with their shared record (a builtin closure whose slots hold a counter shared by the closures of one call), which `Array.fromAsync` does not need but the conformance close reads through its lists; `AggregateError`, which no later story of this slice uses.

## Domain relations

- A call of `Promise.all`, `allSettled` or `any` → its element functions: one to many, one per element, sharing one record of the remaining elements and the list of values or errors — inferable (inferred from ECMA-262 `#sec-performpromiseall`, `#sec-performpromiseallsettled` and `#sec-performpromiseany`, and `crates/swell/src/object/builtin_function.rs:83`, the slots of a built-in function; no ess/1 document declares it: the host model `spec/domains/host.yaml` holds no engine value, and ESS does not restate the slots of ECMA-262, `AGENTS.md`, "Rules").

- AggregateError → its `errors`: one to one, an own data property holding an Array made by CreateArrayFromList at construction — inferable (inferred from `#sec-aggregate-error`; no ess/1 document declares it, for the same reason).

- Bounds. Steps: each element read is the step of the call of `next` and each element function a call; the loop of PerformPromiseAll over n elements queues at most n promise jobs, one step each ("The microtask checkpoint is one entry"). Depth: an element function runs from a job, one re-entry, and returns before the next job runs, so a combined promise over any number of elements takes no depth. Memory: the list of values, the shared record and each element function are charged before they exist; a combined promise whose elements never settle keeps them charged while something reaches it. Termination: a termination in an element function or in the iterator ends the job (or the call of the static) as section 10 of `docs/design/host-interface.md` states; the combined promise stays pending and the jobs behind it stay queued.
