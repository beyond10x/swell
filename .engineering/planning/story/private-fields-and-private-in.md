## Context

Slice 8 of 19, `classes` (`epic:slice-08-classes`; `docs/design/engine.md`, section 12, item 8). This story runs private fields and `#x in`, and is where every part of the slice meets. Private fields: the field kind of an entry of [[PrivateElements]], added by the one add function of `object/private_names.rs` (PrivateFieldAdd: a `TypeError` when the object has the field, the case of a constructor that returns another object and stamps it; the add does not read [[Extensible]]), compiled by `AddPrivateField` into pass 2 of the instance initializer and into the static runs, in source order with the public fields (item 4 of "Classes": "the private add for a private key"); PrivateGet and PrivateSet of a field through `GetPrivate` and `SetPrivate` of `story:private-names-and-private-methods`, which also owns `Target::Private` in `crates/compiler/src/expression.rs`, so every assignment form with a private reference as its target (`=`, compound, `&&=`, `||=`, `??=`, `++`, `--`, destructuring targets, `for (this.#x of ...)`) and private references in optional chains (`o?.#x`, `o?.a.#x`) reach a field through code that exists before this story, which tests them on fields and writes no compiler code for them; and `#x in o` through `PrivateIn` (a `TypeError` when o is no object, else whether PrivateElementFind finds the name, for fields, methods and accessors). It lifts the holds `private field is not supported before slice 8` and `private name in is not supported before slice 8` of `story:class-element-syntax-and-early-errors`, the last two holds of the slice.

It takes the cases and tests of the order of the instance elements, which no story of its own holds: the design leaves that order nothing of its own (the order of the instance elements is the compiled initializer of item 4, pass 1 then pass 2; the call after each SuperCall is item 7's `Dup; InitInstance; Pop`). Its cases are those that need two or more of the derived, field, private-method and static-block parts together (a field initializer that calls a private method, fields of a derived class run after `super()`, a static block that reads a private field). They join this story's list because this story is the one whose landing makes them pass last: it is the first story that depends on all four parts (`story:derived-classes-and-super-call`, `story:public-class-fields`, `story:private-names-and-private-methods`, `story:class-static-blocks`), which land in orders 3 and 4 in no fixed order, and the scan puts each case on the first story whose closure holds every part it needs (`docs/plan/slice-08/scan.awk`, `cl["private-fields"]`). 446 of the folded list's 448 cases are here; 2 needed only the field part and went to `story:public-class-fields`.

Edges: `story:derived-classes-and-super-call`, `story:public-class-fields`, `story:private-names-and-private-methods`, `story:class-static-blocks` (each a part of the combined cases; the last two also write the functions this story extends). Order 5, alone in its order.

A private field may be added to a non-extensible object (the feature `nonextensible-applies-to-private` is excluded, `conformance/test262/features.txt`).

The list is `docs/plan/slice-08/story-private-fields.cases.txt`: the 1,433 cases of the key `private-fields` of `docs/plan/slice-08/scan.tsv` (every class with a private field or `#x in`, and the classes that need two or more parts of orders 3 and 4 together, outside eval; no negative case): `language/statements/class` 669, `language/expressions/class` 624, `language/identifiers` 60 (`start-unicode-*-class*.js`: a class with a private field per code point of a Unicode version, large sources, which the runner's time bound covers), `language/expressions/compound-assignment` 48, `language/expressions/logical-assignment` 21, `language/expressions/in` 11. In revision 1 the 446 folded cases joined it and 2 cases left it for `story:class-static-blocks` (`static-init-sequence.js`, `static-init-abrupt.js`, which need fields and static blocks but no private name). In revision 2, 2 cases joined it from `story:public-class-fields`: `language/{statements,expressions}/class/elements/super-access-from-arrow-func-on-field.js` (`super.x` in an arrow in a field initializer), which need the field part and the lift of `super` in an arrow by `story:derived-classes-and-super-call`, and so the closure of this story (`docs/plan/slice-08/scan.awk`, the part `A`). Their 2,864 runs fail on the plan's base run (the full run of 2026-11-26 on `149e12f1`, equal to `conformance/test262/expected.txt` on `62c7cf59`; slice 8: `test262-slice 08 9302 18455 0 0 9302 5 9297 0`): 2,860 on `class is not supported before slice 8` and 4 as counted refusals. A case of the list that ends on a part outside this story goes to `docs/plan/slice-08/close-later.tsv` by the coordinator's commit, as `story:new-target-meta-property` states.

Design it builds on, by name: `docs/design/engine.md` section 3, "Private names", items 2 and 5, and "Classes", items 4 and 7. No sentence of the design is missing.
