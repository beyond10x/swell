## Context

The twelve methods of `Array.prototype` that walk an array with a callback or flatten it: `forEach`, `every`, `some`, `filter`, `reduce`, `reduceRight`, `find`, `findIndex`, `findLast`, `findLastIndex`, `flat` and `flatMap`. The base has `map` of this family and none of the twelve (the probe of `story:builtin-group-modules`). They are the largest group of failing cases of the slice.

Measured on the base (`309b850`, the run lines of `slot task test262` on it): the twelve directories under `test/built-ins/Array/prototype/` hold 1,434 cases of slice 3, 1,351 failing (`reduce` 234 of 255, `reduceRight` 234 of 255, `filter` 214 of 224, `every` 205 of 213, `some` 205 of 214, `forEach` 175 of 185, `findLast` 15, `findLastIndex` 15, `flat` 15, `find` 14, `findIndex` 14, `flatMap` 11). The static scan of the failing cases of the slice (the decomposition read each case and the harness files it includes for the names of the builtins missing on the base and of the parts of later slices) finds 1,271 failing cases that name a builtin of this story, no builtin of another story of the wave and no part of a later slice: the list `docs/plan/slice-03/story-array-iteration.cases.txt` (1,271 lines; by directory line: `built-ins/Array` 1,263, `built-ins/Object` 6, `built-ins/Error` 1, `language/expressions` 1). A failing case that names builtins of two stories of the wave is on `docs/plan/slice-03/cross-story.tsv` and on no list, and one that needs a later slice is on `docs/plan/slice-03/move-estimate.tsv`; the ten lists, 4,050 cases, were read against the scan again when this plan was revised, and no case of a list names a builtin of another story. That list is this story's bound; a case of it that ends on a part outside this story is reported with that part and the coordinator takes it off the list in the wave record, and a case that ends on a builtin of this story is this unit's to fix. 28 more failing cases of the twelve directories also call `Object.freeze`, `Object.create` or `Object.preventExtensions` and pass on the wave branch; the others need a later slice (`Date`, `RegExp`, arrow functions, `Proxy`) and move at the close. 83 cases that name one of the twelve pass on the base, most on the `TypeError` of the missing function; they run the builtin for the first time here.

Code it builds on, checked on the base: `Array.prototype.map` (`array_map` and `array_map_steps` in the module that becomes `builtins/array/mod.rs`) is the model: O kept on the kept stack, a step per index, the key made again after each call because a call may collect the atom of an index above 2^32 - 2; `array_species_create`, `index_key`, `length_of_array_like` and CreateDataPropertyOrThrow are `pub(crate)` after `story:builtin-group-modules`; the group module `builtins/array/iteration.rs` is that story's, with an id type without a variant and an empty list, and `mod.rs` needs no line for a builtin of the group; the elements of an Array are found without a scan after `story:property-index-and-dense-elements`. No test or fixture of the repository relies on one of the twelve being absent.

## Change

Failing tests first: the Rust tests and language scripts below are written before the code and fail (`TypeError: the value is not a function`), and the 1,271 cases of the list fail on the base.

- `crates/swell/src/builtins/array/iteration.rs`: `forEach`, `every`, `some`, `filter` (`sec-array.prototype.foreach`, `.every`, `.some`, `.filter`, the last with ArraySpeciesCreate), `reduce` and `reduceRight` (`sec-array.prototype.reduce`, `.reduceright`), `find`, `findIndex`, `findLast`, `findLastIndex` with FindViaPredicate (`sec-findviapredicate`), `flat` and `flatMap` with FlattenIntoArray (`sec-array.prototype.flat`, `sec-flattenintoarray`). Twelve builtins, each complete for every this value and argument: an array-like of any length, holes, a length that changes while the walk runs, a callback that throws. They are entries of the group's list in the order of the clauses of 23.1.3, after the keys of the base, as `story:builtin-group-modules` fixes the order. Each walk charges a step per index, so a length of 2^32 - 1 or 2^53 - 1 without elements ends in `Terminated(StepBudget)`; FlattenIntoArray is a loop over an explicit stack, one entry per array being flattened, each charged to the memory budget while it is open, so an array that holds itself flattened with `Infinity` ends in a budget and never in a Rust stack overflow; O, the callback's result array and every open source are on the kept stack across each call.
- Tests, each in both collection modes (`test-collect`): `crates/swell/tests/builtins_array_iteration.rs` (new): one test per builtin for its property (`length`, `name`, attributes, not a constructor) and its steps, among them `walks_skip_holes_and_see_a_length_read_once`, `reduce_without_an_initial_value_on_an_empty_array_throws`, `find_visits_holes_as_undefined_and_find_last_walks_backward`, `filter_uses_the_species_and_keeps_the_order`, `flat_of_depth_zero_one_and_infinity`, `flat_map_flattens_one_level_only`, `flat_of_an_array_that_holds_itself_ends_in_a_budget` (under a small step budget and under a small memory budget: `Terminated`, the test names which), `a_walk_of_2_32_minus_1_indices_ends_in_the_step_budget`, `each_walk_charges_a_step_per_index`, `what_a_walk_holds_survives_a_collection_in_its_callback`, and eleven tests over one helper, `<method>_callback_reaches_the_reentry_limit_on_the_promised_stack`, one per method so that each is timed alone (through `reach_through` of `tests/support/stack.rs`: `[0].forEach(f)`, `[0].every(f)`, `[0].some(f)`, `[0].filter(f)`, `[0].reduce(f, 0)`, `[0].reduceRight(f, 0)`, `[0].find(f)`, `[0].findIndex(f)`, `[0].findLast(f)`, `[0].findLastIndex(f)`, `[0].flatMap(f)`, eleven runs, on seven eighths of `min_stack_bytes()`). `crates/swell/tests/language/` (new files): `builtin-array-for-each-every-some.js`, `builtin-array-filter.js`, `builtin-array-reduce.js`, `builtin-array-find.js`, `builtin-array-flat.js`. No test or script of this story calls a builtin another story of the wave delivers: a result is compared element by element or through `join`; a walk whose callback changes the receiver uses `push`, an assignment to an index or to `length`, and `delete`, not `pop`, `shift` or `splice`; a target that is not extensible or an element that cannot be defined is made with `Object.defineProperty` or, in a unit test of `iteration.rs`, with `prevent_extensions` and SetIntegrityLevel, not with `Object.preventExtensions` or `Object.freeze`; the species tests are unit tests of `iteration.rs` that set `constructor[@@species]` through the well-known symbol of the realm, as the tests of `map` do, since no script can name that symbol before slice 6.
- Time of the tests ("Tests stay fast", the `AGENTS.md` of the folder that holds the repository, and the `AGENTS.md` of the repository once `story:gate-test-steps-within-budget` has landed): the unit times each test before it adds it, names in its report each one over 5 s with its time and the reason, and adds none over 60 s; a product several tests share is built once inside one test function or is a committed generated file, never in a `OnceLock` (the test steps run a process per test); no test makes a network request; the unit runs its own test binaries and never the whole gate, which runs once on the wave branch.
