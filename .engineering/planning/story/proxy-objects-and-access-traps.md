## What later stories reuse

The object kind `Proxy` (`object/proxy.rs`) and its arms in the dispatch, which `story:proxy-descriptor-prototype-and-extensibility-traps` fills for the seven remaining traps; `object/invariants.rs` with the checks of this story, which that story completes and `story:host-object-overrides` calls on an override's result; the walks of the chain that hand over to a parent's own method, which host objects with overrides use; the trap lookup `GetMethod(handler, name)` with its revocation check.

## Domain relations

- A Proxy → its target and its handler: many to one each (several proxies may share one target or handler), both set at creation, both cleared by revocation, never set again — inferable (inferred from ECMA-262 `#sec-proxycreate` and `#sec-proxy.revocable`; no ess/1 document declares it: the host model `spec/domains/host.yaml` holds no engine value, and ESS does not restate the slots of ECMA-262, `AGENTS.md`, "Rules").
- A revoke function → its Proxy: one to zero or one, cleared at the first call — inferable (inferred from `#sec-proxy-revocation-functions`; no ess/1 document declares it, for the same reason).
