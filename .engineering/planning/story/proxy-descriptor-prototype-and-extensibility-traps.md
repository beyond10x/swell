## Context

## Change

Failing tests first: the tests below are written before the code and fail on the base of this story (the seven traps are not read: a handler's `ownKeys` is never called).

- `crates/swell/src/object/proxy.rs`: the seven methods (`#sec-proxy-object-internal-methods-and-internal-slots-getprototypeof` and the six after it): ValidateNonRevokedProxy, GetMethod of the trap, without a trap the target's own method (as today), with one the Call of the trap, then the target facts its clause compares with, read from the target after the trap returns (the target's prototype, whether it is extensible, its descriptor of the key, its own keys with their descriptors), then the checks of its clause below. [[DefineOwnProperty]] passes FromPropertyDescriptor of the argument to the trap and takes ToBoolean of the result (false: the answer false, no check); [[GetOwnProperty]] takes ToPropertyDescriptor and CompletePropertyDescriptor of an Object result; [[OwnPropertyKeys]] takes CreateListFromArrayLike of the result with the element types String and Symbol (`crates/swell/src/builtins/function.rs` line 200, made `pub(crate)` by `story:reflect-namespace`: a parameter of element types, or a wrapper beside it) and finds a repeated key with a `KeyedMap` of the keys seen (`crates/swell/src/heap/map.rs`, charged by `KeyedMap::table_bytes_for` before it is made, dropped at the end of the call).
- `crates/swell/src/object/invariants.rs`: IsCompatiblePropertyDescriptor (`validate_and_apply_property_descriptor`, `crates/swell/src/object/ordinary.rs` line 248, with `object` `None`), CompletePropertyDescriptor, and the 21 invariants of the seven clauses, numbered here, each a function of (the target facts it compares with, the trap result) that reads no object and answers which invariant broke and for which key; the Proxy method turns that answer into a `TypeError` whose message names the trap, the key and the number, and `story:host-object-overrides` calls the same functions with the facts it recorded for a host object in place of the target's (the shape of the checks of `story:proxy-objects-and-access-traps`). The facts are a prototype (`Option` of an object), a flag extensible, a descriptor of the key (`Option<Property>`) and a list of own keys with their descriptors, each passed only to the invariants that read it.
  - [[GetPrototypeOf]]: I1 the result is neither an Object nor `null`; I2 the target is not extensible and the result is not SameValue with the target's prototype.
  - [[SetPrototypeOf]]: I3 the result is true, the target is not extensible and the value set is not SameValue with the target's prototype.
  - [[IsExtensible]]: I4 ToBoolean of the result differs from the target's IsExtensible.
  - [[PreventExtensions]]: I5 the result is true and the target is extensible.
  - [[GetOwnProperty]]: I6 the result is neither an Object nor `undefined`; I7 the result is `undefined` and the target's property is non-configurable; I8 the result is `undefined`, the target has the property and is not extensible; I9 the result is not compatible with the target's property by IsCompatiblePropertyDescriptor (a property the target lacks reported for a non-extensible target among them); I10 the result is non-configurable and the target's property is absent or configurable; I11 the result is non-configurable and non-writable and the target's property is writable.
  - [[DefineOwnProperty]] (after a true result): I12 the target lacks the property and is not extensible; I13 the descriptor sets `configurable: false` and the target lacks the property; I14 the descriptor is not compatible with the target's property by IsCompatiblePropertyDescriptor; I15 the descriptor sets `configurable: false` and the target's property is configurable; I16 the target's property is a non-configurable, writable data property and the descriptor sets `writable: false`.
  - [[OwnPropertyKeys]]: I17 an element of the result is neither a String nor a Symbol; I18 a key is repeated; I19 a non-configurable key of the target is missing; I20 the target is not extensible and one of its configurable keys is missing; I21 the target is not extensible and the result holds a key the target lacks.
- The walks and enumerations that read these methods need no change of their own and are checked by the guard: `for-in` (EnumerateObjectProperties over [[OwnPropertyKeys]], [[GetOwnProperty]] and [[GetPrototypeOf]]), `Object.keys`, `entries`, `assign`, `freeze`, `seal`, `isFrozen`, `JSON.stringify`, `instanceof` (OrdinaryHasInstance over [[GetPrototypeOf]]), the `with` statement's `@@unscopables` and HasBinding, and the spread of an object literal (CopyDataProperties).
