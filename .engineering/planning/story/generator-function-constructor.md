## Context

Slice 7, third wave (`epic:slice-07-generators`). `%GeneratorFunction%` (`#sec-generatorfunction-constructor`) makes a generator function from source text at run time: CreateDynamicFunction of kind generator (`#sec-createdynamicfunction`), through the path `story:eval-and-function-constructor` built for kind normal (`crates/swell/src/dynamic_code.rs`, `create_dynamic_function`, line 671) and the host's hook HostEnsureCanCompileStrings (`#sec-hostensurecancompilestrings`), which the standard calls with the compilationType `FUNCTION` for every kind, so `CompilationType::Function` of `crates/swell/src/host/hooks.rs` (line 129) serves as it is and the host interface does not change. It depends on `story:generator-functions-and-suspended-frames` (`%GeneratorFunction.prototype%`, `%GeneratorPrototype%`, the generator branch of `instantiate_function`). `%GeneratorFunction%` is no global: a script reaches it as `Object.getPrototypeOf(function* () {}).constructor`. The consumer of the slice needs slice 10, not this story.

This story removes no refusal.
