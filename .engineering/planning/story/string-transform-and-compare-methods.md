## Context

Eleven methods of `String.prototype` that make a String from a String or compare two: `repeat`, `padStart`, `padEnd`, `trim`, `trimStart`, `trimEnd`, `toLowerCase`, `toUpperCase`, `toLocaleLowerCase`, `toLocaleUpperCase` and `localeCompare`. None exists on the base (the probe of `story:builtin-group-modules`). The sixteen that read and search are `story:string-access-and-search-methods`, in a file of its own.

Measured on the base (`309b850`, the run lines of `slot task test262` on it): the eleven directories under `test/built-ins/String/prototype/` hold 296 cases of slice 3, 286 failing (`trim` 126 of 128, `toLowerCase` 26, `toLocaleLowerCase` 26, `toUpperCase` 24, `toLocaleUpperCase` 24, `repeat` 11, `localeCompare` 11, `padStart` 10, `padEnd` 10, `trimStart` 9, `trimEnd` 9). The static scan of the failing cases of the slice (the decomposition read each case and the harness files it includes for the names of the builtins missing on the base and of the parts of later slices) finds 271 failing cases that name a builtin of this story, no builtin of another story of the wave and no part of a later slice: the list `docs/plan/slice-03/story-string-transform.cases.txt` (271 lines; `built-ins/String` 265, `built-ins/Object` 6). A failing case that names builtins of two stories of the wave is on `docs/plan/slice-03/cross-story.tsv` and on no list, and one that needs a later slice is on `docs/plan/slice-03/move-estimate.tsv`; the ten lists, 4,050 cases, were read against the scan again when this plan was revised, and no case of a list names a builtin of another story. That list is this story's bound; a case of it that ends on a part outside this story is reported with that part and the coordinator takes it off the list in the wave record.

Cases that pass on the base and stop passing with this story, which it cannot keep. Three cases of slice 6, `String/prototype/padEnd/exception-symbol.js`, `padStart/exception-symbol.js` and `toLowerCase/this-value-tostring-throws-symbol.js`, call the method with `Symbol()` inside `assert.throws(TypeError, ...)`: on the base the member `String.prototype.padEnd.call` throws the `TypeError` because the method is missing, before `Symbol` is read; with the method the run ends on `ReferenceError: Symbol is not defined` until slice 6. Two cases of slice 18, `test/annexB/built-ins/String/prototype/trimLeft/reference-trimStart.js` and `trimRight/reference-trimEnd.js`, assert that `trimLeft` is the same value as `trimStart`: undefined and undefined on the base, a function and undefined once `trimStart` exists, until Annex B brings the alias. The five are cases of later slices and are not moved; `story:slice-03-conformance-close` lists them among the runs that passed on the base of the wave and no longer do. The decomposition read every passing case of the other slices that names a builtin of slice 3 (52 cases) and found no other of this story.

What the tables of slice 5 withhold. The design gives case mapping outside ASCII and `normalize` to slice 5, where `swell-unicode` gets its tables, and says the engine "refuses the input with a defined outcome instead of guessing" until then (`docs/design/engine.md`, section 12, "A part before its slice"; this settles the epic's open point on the tables). So the four case methods are delivered for every String whose code units are all below 0x80, where the mapping of the Unicode Standard is that of the 26 letters and nothing else, and refuse any other String; `localeCompare` is delivered the same way: for two Strings of ASCII code units the order of their code units is a consistent total order and canonical equivalence is identity, and with any other code unit it would have to honour canonical equivalence (`sec-string.prototype.localecompare`), which needs the decompositions of slice 5. Measured: 13 cases of the five directories hold text outside ASCII (comments removed: a character, or a `\u` escape above 007F; `special_casing`, `special_casing_conditional`, `supplementary_plane` and `Final_Sigma_U180E` of the lower-case methods, `special_casing` and `supplementary_plane` of the upper-case ones, `localeCompare/15.5.4.9_CE.js`) and move to slice 5 at the close with the 9 failing cases of `normalize`; the list above holds none of them.

Design it builds on: a precondition that holds before the wave (the design author's change of 2026-11-21). `docs/design/engine.md`, section 12, "A part before its slice", gives the four case methods and `localeCompare` the third form: each exists in slice 3, answers a String whose code units are all below 0x80 as the standard does, and refuses any other until slice 5; `localeCompare` refuses when the this value or `that`, each converted to a String, has a code unit of 0x80 or above. `docs/design/host-interface.md`, section 13, "A refusal raised by a builtin method": the refusal comes after the steps the clause gives before the mapping or the comparison (RequireObjectCoercible, then ToString), so an error those steps throw is thrown instead of it and is not counted; it is a `SyntaxError` whose prototype is `%SyntaxError.prototype%` of the method's realm and whose `message` is exactly `case mapping outside ASCII is not supported before slice 5` or `comparison outside ASCII is not supported before slice 5`, with no position after it; `swell_syntax::message_kind` reads either as a refusal of slice 5; each such throw moves `refusals()` by 1, caught or not.

Code it builds on, checked against `story:builtin-group-modules`: `builtins/string/mod.rs` has the function for the first two steps of a method (RequireObjectCoercible, ToString) and `StringBuilder` (a step per code unit copied, the `RangeError` at `string_length` before the units exist, the memory asked before it grows); the group module `builtins/string/transform.rs` is that story's, with an id type without a variant and an empty list, and `mod.rs` needs no line for a builtin of the group; `is_str_white_space` is `pub(crate)` in `crates/swell/src/ops/conversion.rs`. StringPad and TrimString have no other caller in the slice and are written here. No test or fixture of the repository relies on one of the eleven being absent.
