## Context

The global functions slice 3 delivers are the four URI functions: the design gives `parseInt` and `parseFloat` to slice 4 and took `isNaN`, `isFinite` and `eval` in slice 2 (`docs/design/engine.md`, section 12, "A part before its slice": "the URI functions with slice 3"). With them this story delivers the value property `globalThis` (`HOST-155`, marked `[slice 3]`; `crates/swell/src/builtins/global.rs` says so in its module comment) and `Error.isError`, which the Error constructors of slice 1 left out (`docs/plan/waves.md`, "What later slices take over"). Each is small, none shares a file with another story of the wave, and together they are the only writers of the realm's registration files in the wave.

Measured on the base (`309b850`, the run lines of `slot task test262` on it): the four directories `test/built-ins/{decodeURI,decodeURIComponent,encodeURI,encodeURIComponent}/` hold 169 cases, 165 failing; `test/built-ins/Error/isError/` 8, all failing; three cases end with `globalThis is not defined`. The static scan of the failing cases of the slice (the decomposition read each case and the harness files it includes for the names of the builtins missing on the base and of the parts of later slices) finds 125 failing cases that name a builtin of this story, no builtin of another story of the wave and no part of a later slice: the list `docs/plan/slice-03/story-global.cases.txt` (125 lines; by directory line: `built-ins/decodeURIComponent` 41, `built-ins/decodeURI` 40, `built-ins/encodeURI` 18, `built-ins/encodeURIComponent` 18, `built-ins/Error` 5, `built-ins/Object` 3). A failing case that names builtins of two stories of the wave is on `docs/plan/slice-03/cross-story.tsv` and on no list, and one that needs a later slice is on `docs/plan/slice-03/move-estimate.tsv`; the ten lists, 4,050 cases, were read against the scan again when this plan was revised, and no case of a list names a builtin of another story. That list is this story's bound; a case of it that ends on a part outside this story is reported with that part and the coordinator takes it off the list in the wave record. 48 more failing URI cases also call `String.fromCharCode`, `charAt` or `toUpperCase` (`story:string-access-and-search-methods`, `story:string-transform-and-compare-methods`) and pass on the wave branch. The URI cases are the longest runs of the slice: fourteen of the runner's twenty `test262-steps` lines of the base are theirs, 3,013,941 steps each while the function is still missing (`.out/test262-base/count.log` of the unit's base run); each loops over up to 65,536 code units.

Code it builds on, checked on the base and against `story:builtin-group-modules`: CodePointAt and UTF16EncodeCodePoint are functions of `crates/swell/src/builtins/string/mod.rs` after that story, tested there, under a mark whose reason names this story and `story:string-access-and-search-methods`; `StringBuilder` is in the same module. `create_global_functions` answers the pair `(is_finite, is_nan)` and `Intrinsics` has one field per intrinsic (`crates/swell/src/realm/intrinsics.rs`); `set_default_global_bindings` defines the global properties from a list of names and intrinsics (`crates/swell/src/realm/global_object.rs`); the realm record has the global `this` value (`global_this`, `crates/swell/src/realm/mod.rs`, line 73), which `host_50_setup_this_is_script_this` (`crates/swell/tests/scripts.rs`) reads through `this`; the Error constructors have no id type of their own (`BuiltinId::ErrorConstructor` and `ErrorPrototypeToString`, `crates/swell/src/object/builtin_function.rs`), and an Error object is an ordinary object with `OrdinaryData::Error`; `ErrorKind::UriError` exists. No test or fixture of the repository relies on one of the six names being absent (`host_49_setup_closure_and_clause_19_globals` in `crates/swell/tests/limits_scripts.rs` lists names that exist and is not changed).
