# swell: reference data of Math, the functions sin, cos, tan, atan, asin, acos and atan2
# (docs/design/engine.md, decision 6, "Reference data of Math"), read by
# crates/num/tests/math_trig.rs.
# Tool: GNU bc 1.08.2, run as bc -l, driven by a POSIX sh script that was run once outside the
# repository and is not committed. The procedure is that of the design's "The tool that makes
# the lines", steps 1 to 6:
# 1. An argument's bits are read with ibase=16 as one integer; sign, biased exponent and the 52
#    stored bits give the sign, an integer mantissa m and a binary exponent q, and the argument
#    is m x 2^q with that sign.
# 2. The scale: S0 = max(400, 2 x (k1 + k2) + 100) + D, k the count of fractional binary digits
#    of an argument (-q, or 0 for q >= 0; k2 is that of the second argument of atan2 and 0
#    otherwise), D the count of integer decimal digits of the larger argument (0 below 1). Each
#    line is computed at S and at S + 60; where the two enclosures differ, S grows by 400 while
#    it stays at most 4000 and the line is computed again. Lines left out in doubt: 0.
# 3. The functions, with pi = 4 x a(1): sin = s(x); cos = c(x); tan = s(x)/c(x); atan = a(x);
#    asin(x) = 2 x a(x/(1 + sqrt(1 - x^2))); acos(x) = 2 x a(sqrt((1 - x)/(1 + x))), and pi
#    for x = -1; atan2(y, x) = a(y/x) for x > 0, that plus pi (y >= 0) or minus pi (y < 0) for
#    x < 0.
# 4. The two Numbers: for the magnitude r of the result, e with 2^e <= r < 2^(e+1), found by
#    comparing r with powers of two and clamped below at -1022; M = r x 2^(52 - e) cut to an
#    integer with scale=0; the two Numbers are M x 2^(e - 52) and (M + 1) x 2^(e - 52), their
#    bits (e + 1022) x 2^52 + M and (e + 1022) x 2^52 + M + 1 written with obase=16, the sign
#    bit 2^63 added to both for a negative result, so that the first is the one nearer to zero.
#    Where r x 2^(52 - e) is within 10^-(S - 40) of an integer, the value is taken as that
#    integer and both Numbers are it; no line of this file is such.
# 5. The arguments, per function in this order: the special ones, 200 drawn, and for sin, cos
#    and tan the 40 nearest to a multiple of pi/2 (step 6). The special ones: for sin, cos and
#    tan 20: 1, -1, 2^-30, 2^-27, 0.5, 2, 2^10, 2^100, 2^500, 2^1000, 2^1023, the largest
#    Number and its negative, the Numbers below and above pi/4 (3FE921FB54442D18,
#    3FE921FB54442D19), the Numbers nearest to pi/2 and to pi, 6381956970095103 x 2^797 (the
#    Number nearest to a multiple of pi/2 in Muller, Handbook of Floating-Point Arithmetic,
#    11.2), the smallest subnormal and 2^-1022; for atan 18: 1, -1, 2^-30, 0.5, 2, 1/16, 1/8,
#    3/16, 15/16, 1 - 2^-53, 1 + 2^-52, 2^26, 2^53, 2^60, 2^100, the largest Number, the
#    smallest subnormal and 2^-1022; for asin 14: 1, -1, 0.5, -0.5, 2^-30, 2^-27, 1 - 2^-53 and
#    its negative, the Numbers nearest to sqrt(2)/2 and sqrt(3)/2, 1/16, 15/16, the smallest
#    subnormal and 2^-1022; for acos 14, the list of asin without 1 (the draft fixes acos(1))
#    and with 2^-53 after 15/16; for atan2 16 pairs (y, x): (1, 1), (-1, -1), (1, -1), (-1, 1),
#    (3, 4), (-3, -4), (2^60, 1), (1, 2^60), (2^61, 1), (1, 2^59), (1, -2^60), the largest
#    Number twice, the largest Number and its negative, the smallest subnormal and three times
#    it, 2^-1022 and -1, the largest Number and the smallest subnormal. Lines with an argument
#    below 2^-500: two for each of sin, cos, tan, atan, asin and acos, three for atan2.
#    The drawn arguments come from Knuth's 64-bit linear congruential generator (multiplier
#    6364136223846793005, increment 1442695040888963407, modulus 2^64, seed 1, computed in bc
#    with %), one stream over the functions in the order sin, cos, tan, atan, asin, acos,
#    atan2. An argument takes two draws d1 and d2: its sign is bit 63 of d1, its binary
#    exponent low + ((d1 mod 2^63) / 2^32 mod (high - low + 1)), its 52 stored bits d2 / 2^12,
#    with [low, high] by the number i of the argument, 1 to 200: for sin, cos and tan
#    [-26, 1023] for an odd i and [-3, 30] for an even one; for atan [-30, 60] and [-4, 4]; for
#    asin and acos [-30, -1] and [-4, -1]. atan2 takes four draws per pair: y as above with its
#    exponent in [-100, 100], then x with the exponent of y plus
#    ((d3 mod 2^63) / 2^32 mod 141) - 70.
# 6. What bc cannot do. (a) It does not search: the arguments nearest to a multiple of pi/2 are
#    found in bc by continued fractions, at scale 1400: for q = -20 + floor(980 j / 39), j = 0
#    to 39, the continued fraction of the fractional part f of 2^q x (2/pi), pi as 4 x a(1); at
#    each level, with the denominators k (the one before) and m (the last) and the next partial
#    quotient z, the semiconvergent k + u x m with u the largest of 1 to z that keeps it below
#    2^53 (u = z gives the next convergent) is a candidate when it is at least 2^52, and its
#    distance is that of its multiple of f to the nearest integer. The argument is d x 2^q for
#    the candidate d of the smallest distance. Every q had a candidate: 40 arguments. The
#    closest approach |x - k pi/2| among them is 2^-57.93 (q = 80). (b) The tiny arguments are
#    slow: they are limited as step 5 says.
# The special values (NaN, an infinite argument, a zero argument, the results the draft fixes)
# are written by hand in the test.
